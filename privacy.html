This website

The calculators on this site run entirely in your browser. We do not collect, store or sell the numbers you type, and the site sets no tracking cookies of its own. The site is hosted on GitHub Pages, which may keep standard server logs under GitHub's own privacy statement.

Clearline Metrics (Google API access)

Clearline Metrics is an internal reporting tool used only by Clearline Labs to read analytics for the YouTube channels we own and operate. With the channel owner's consent it requests read-only access (YouTube Analytics and YouTube Data, read-only scopes) to retrieve aggregate statistics such as views, watch time, audience retention, impressions and click-through rate. This data is stored privately on our own computer, used only to improve our own videos, and is never sold, shared with third parties, or used for advertising. No data from other users or channels is accessed. Access can be revoked at any time at myaccount.google.com/permissions.

Clearline Metrics' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
